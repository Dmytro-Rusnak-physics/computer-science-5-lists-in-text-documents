# Місія «Майстер списків» — Інформатика, 5 клас

Інтерактивна навчальна гра за темою **«Списки в текстових документах»**.

## Запуск
Відкрийте [гру на GitHub Pages](https://dmytro-rusnak-physics.github.io/computer-science-5-lists-in-text-documents/).

## Що є в грі
- 10 тестових завдань із миттєвим зворотним зв’язком.
- Марковані, нумеровані та багаторівневі списки.
- Вибір типу списку для різних ситуацій.
- Створення списків, вибір маркерів і способів нумерації.
- Налаштування відступів за допомогою лінійки.
- Перетворення списку на звичайний текст.
- Автоматичний підрахунок результату та оцінка за 12-бальною шкалою.
- Пояснення правильних відповідей і час проходження.

Гра не запитує ім’я, прізвище чи клас учня. Відповіді обробляються у браузері; реєстрація не потрібна.

## Вміст
- `index.html` — повна гра (HTML, CSS, JavaScript в одному файлі).
